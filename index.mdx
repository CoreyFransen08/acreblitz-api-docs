title: "AcreBlitz ESA API"
description: "ESA assessments, compliance information, and reports for pesticide applications"
---

Use the AcreBlitz V2 API to assess applications, retrieve compliance requirements, and provide a portal for mitigation selection.

Base URL: `https://esa.acreblitz.com`. All API routes use `/api/v2` and require your provider API key.
